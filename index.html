“I run a homelab.”

  • One ~25 MB Go binary, pure-Go SQLite, no CGO
  • Ollama out of the box; OpenAI-compatible or Claude if you prefer
  • Passkeys, argon2id, CSRF protection, SSRF-blocked fetches
  • Scheduled backups, OPML exports and a daily digest email

docker compose

cd ember/deploy && cp .env.example .env
# set EMBER_SESSION_KEY and EMBER_ADMIN_PASSWORD in .env
docker compose up -d
